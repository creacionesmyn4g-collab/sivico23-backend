Diagrams UML (PlantUML) para SIVICO23 - Copia en carpeta `uml`
=============================================================

Esta carpeta contiene una copia agrupada de los diagramas y scripts UML generados para el proyecto.

Archivos incluidos:

- `backend_class_diagram.puml`
- `frontend_component_diagram.puml`
- `sequence_login.puml`
- `render_diagrams.sh` (script bash para render local)
- `render_diagrams.ps1` (script PowerShell para render en Windows)
- `render-diagrams.yml` (copia del workflow de GitHub Actions)
- `output/` (carpeta para PNG renderizados; contiene `.gitkeep`)

Para renderizar localmente se pueden usar los scripts incluidos o la extensión PlantUML en VSCode.

Los PNG resultantes se colocan en `output/` dentro de esta carpeta.
